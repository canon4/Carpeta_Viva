# Ontología

- `core.ttl`: ontología núcleo (8 clases), ver ADR-0006.
- `ejemplo-sintetico.ttl`: datos ficticios para pruebas.
- `consultas.rq`: consultas de competencia SPARQL.
- `validar.py`: `pip install rdflib && python ontologia/validar.py`.

El grafo no contiene datos personales ni contenido de documentos.
